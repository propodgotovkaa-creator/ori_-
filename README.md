# Хранитель волшебного леса

## [▶ Играть — открыть волшебный лес](https://propodgotovkaa-creator.github.io/ori/)

Игра открывается по ссылке выше. На этой странице GitHub находятся её файлы. Если после обновления виден пустой экран, обновите страницу сайта: браузер мог сохранить старую версию.

Браузерная игра на Phaser 3.90.0. Оригинальные изображения; 11 карточек на звук Л, без подписей и распознавания речи. Phaser включён в проект, внешний CDN не нужен.

Запуск: `python3 -m http.server 4173`, затем `http://localhost:4173/`.
Проверки: `npm test` (Node 18+). Сборка не требуется.

Управление: ←/→ или A/D — движение, ↑/пробел — прыжок, Escape — пауза. Кристаллы собираются автоматически при касании. Кнопки снизу работают мышью и касанием. После меню и карточки фокус возвращается игровому canvas. Прогресс сохраняется в sessionStorage текущей вкладки.

Пять одобренных мягко прорисованных пейзажей находятся в `assets/forest/soft/`. Исходные PNG сохранены без изменения. Рельеф в `scenery.js` задан по нарисованной поверхности; Phaser отвечает за ускорение, скорость и гравитацию, а столкновение с рельефом выравнивает ноги по контуру. Исправление бега использует актуальный центр физического тела, а не позицию объекта до завершения физического шага.

В браузере проверены: движение стрелками в обе стороны, прыжок, спуск и подъём, переход первого стыка, открытие карточки и возврат управления после её закрытия. Стыки пейзажей ещё требуют художественной доводки. Проверка реального планшета и Genially не выполнена. Игра опубликована на GitHub Pages.

Для разработчика: `?test=1` включает отладочный интерфейс и диагностические DOM-атрибуты позиции/последней игровой клавиши. Обычная ссылка их не включает. Никаких сетевых запросов с этими данными нет.

Phaser — MIT, лицензия в `vendor/PHASER-LICENSE.md`. Звук полностью отключён, аудио не загружается.


### Паучки и кристаллы
Шесть паучков открывают испытание «Проведи светлячка». Слог ЛО, ЛУ или ЛА задан на всю встречу. Сначала путь последовательно подсвечивается; затем подсказка исчезает, и ребёнок повторяет маршрут по развилкам, произнося слог. У каждой развилки два одинаково подсвеченных варианта. Светлячок проходит весь выбранный путь, не прерывая ребёнка. Только после последнего шага путь сравнивается с образцом. Верный освобождает героя, неверный предлагает «Попробовать ещё раз». «Показать путь ещё раз» повторяет тот же маршрут с начала. Пауза сохраняет показ и полёт. После четырёх шагов герой автоматически освобождается. Голос не распознаётся, взрослый слушает ребёнка.

Кристаллы собираются автоматически при касании. Пять из одиннадцати требуют прыжка.

Карточки раскрываются из светящегося шара, летящего от кристалла к центру экрана. Картинка остаётся в том же голубом шаре. Надписей и отдельной кнопки нет: после называния нажмите на шар (или Enter/пробел при фокусе на нём). Экранные стрелки ← → ↑ расположены вместе внизу слева.

Пропущенный кристалл переносится вперёд, когда уходит за левый край камеры. Его ID и картинка сохраняются; собранные не возвращаются. Позиции сохраняются в сессии вкладки.

### Финал: свет вернулся домой
После последней картинки начинается нарисованная сцена у древнего дерева. Все 11 кристаллов возвращают свет в дупло, оживают прожилки коры, появляются светлячки. Герой подходит к дому и прощается. Затем доступно «Новое путешествие». Без музыки и звуков. Иллюстрации и описание: `assets/ending/ART.md`. Предпросмотр: `?test=1&ending=1` (не изменяет собранные кристаллы).

### Выбор позиции звука Л
В меню четыре набора: начало (11 слов), середина (11), конец (10), стечения согласных (10). Состав задан в `vocabulary.js`. Набор выбирается до старта, сохраняется с текущим прохождением; смена набора начинает новую прогулку. Счётчик, возвращающиеся кристаллы и финальная сцена используют размер выбранного набора.

Паутинки последовательно чередуют слоги: середина — АЛА, ОЛО, УЛУ, ЫЛЫ; конец — АЛ, ОЛ, УЛ, ЫЛ; стечения — КЛУ, ПЛЫ, СЛА, ПЛО. Начальный набор сохраняет ЛО, ЛУ, ЛА. Повтор попытки оставляет тот же слог и маршрут. Голос не записывается и не проверяется автоматически.

Новые картинки хранятся в трёх прозрачных атласах 4×3; в шаре показывается только одна ячейка. Обновлённый герой: `assets/character/hero-v2.png`. Промпты иллюстраций: `art-direction/positions-art.md`.

### Управление
Герой двигается только при удержании ←/→ на клавиатуре или экранных кнопок. ↑, W, пробел или верхняя экранная кнопка — прыжок. Все три экранные кнопки находятся справа внизу, ↑ по центру над ← и →. Можно одновременно удерживать движение и нажимать прыжок. Прыжок фиксированной высоты. При отпускании кнопки, потере фокуса или открытии задания движение прекращается. Касание самого леса не вызывает прыжок.

Кристаллы размещаются по seed нового прохождения на подходящих участках земли. Сохранённое прохождение сохраняет позиции. Первый кристалл меняет расстояние от старта. Слоги меняются по количеству пройденных паутинок, поэтому пропуск паука не нарушает последовательность.
