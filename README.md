# Хранитель волшебного леса — звук Р

Отдельная версия игры для звука Р в репозитории `ori_-`. Исходная версия на Л остаётся в `ori`.

## Слова и паутинки

- **В начале слова** (11 картинок): Рука Роза Ромашка Рысь Радуга Ракета Рыба Ракетка Руль Розетка Рубашка. Слоги: РА РО РУ РЫ.
- **В середине слова** (10 картинок): Корова Барабан Пирамидка Гитара Баран Горох Корона Кукуруза Подарок Нора. Слоги: АРА ОРО УРУ ЫРЫ.
- **В конце слова** (10 картинок): Помидор Сахар Инжир Мухомор Вор Мусор Катер Самовар Топор Комар. Слоги: АР ОР УР ЫР.
- **В стечениях согласных** (11 картинок): Груша Крот Дрова Крокодил Зебра Морковь Вертолёт Врач Торт Корзина Гранат. Слоги: ГРА БРО ДРЫ КРУ.

Пирамидка — детская игрушка из колечек; сахар — кубиками; гранат — фрукт.
42 иллюстрации в четырёх прозрачных атласах 4×3. Точные слова и порядок ячеек — `vocabulary.js`. Промпты — `art-direction/r-art.md`.

## Игра

Удерживайте ←/→ для движения; ↑, W или пробел — прыжок. Экранные кнопки справа внизу. Кристаллы собираются при касании, часть висит в воздухе. Картинка открывается в голубом шаре; нажатие на шар продолжает игру. Пропущенные кристаллы появляются впереди. Новое прохождение меняет их позиции; продолжение сохраняет прежние.

Паук открывает испытание на память: сначала показывается путь, затем ребёнок повторяет его и произносит указанный слог. Проверка пути происходит только после завершения всей попытки. Слоги циклически меняются по числу пройденных паутинок; повтор попытки сохраняет слог. Голос не записывается и не распознаётся. Музыка и эффекты отключены.

После всех картинок кристаллы возвращают свет древнему дереву. Количество кристаллов и финал соответствуют выбранному набору. Сохранение версии Р отделено от версии Л.

## Запуск и проверки

Проверки: `node --test tests/*.test.mjs` (Node 18+).
GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
